# 界面实现基线

参考图：concept.png（1505×1045）。统一桌面工作台，无特定系统窗口装饰。

- 真白色主画布；浅冷灰侧栏；主色 #176b57，文字 #17232f，次级 #657585，边框 #dce4e9。
- 侧栏 250px，顶部路径栏 56px，内容横向内边距 32px。标题 32/40px，正文 14/22px，表单与按钮 14px；中文系统字体。
- 图标使用 lucide 20px、1.8px 线宽；品牌 G 为原生文字。选中导航浅青底/左侧绿线。
- 控件 44px 高，8px 圆角；表格浅灰表头，结果行不做重复嵌套卡片。主要结果区域为单边框。
- 网站诊断主屏忠实采用参考：标题、网址/页面上限/渲染开关/开始按钮，状态三列，结果/快照/对比标签，空态，底部说明。
- 功能必要扩展：项目选择和创建/删除、错误提示、状态文本、提供商选择、历史记录；均沿用相同设计系统。模型设置提供明显 Key 会话/加密状态。
- AI 改写：两列编辑器、目标与提供商设置、差异列表；引用监测：配置表单、批次列表和来源表；模型设置：配置表和组件状态。
- 900px 以下侧栏收窄/隐藏导航文本，表单自动换行，编辑器改单列；结果表横向滚动，不裁掉关键控件。
- 无虚构的种子诊断、指标、引用或改写稿。截图只展示空态或实测生成数据。
