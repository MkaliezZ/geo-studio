## 验证证据

- `npm run build`：TypeScript、Vite renderer、Electron main/preload 构建通过。
- `npm test`：33 passed / 0 failed。实际组件测试在自建 loopback 站点执行两次诊断，中间移除 noindex，验证复检识别已解决；另验证真实 Chromium 能取得脚本生成的中文正文。自动测试中的供应商调用使用受控响应，不发起付费 API 调用；真实 DeepSeek 验收单列记录。
- 本轮功能回归修复：诊断并发准入、密钥并发写入、解密失败后设置恢复、删除项目时清理采集文件、删除项目后拒收迟到的改写结果、robots 阶段取消状态；改写视图按项目隔离，避免迟到响应污染当前项目。
- 隔离界面验收：改写生成→人工修改→保存→差异查看→刷新恢复→Markdown 导出；双模型监测→采样→取消→JSON 导出。已核验导出文件内容，普通回答链接不计入联网引用率分母，前端无 warning/error，页面未出现“开源/MIT”。
- robots 单文件组件启动实测约 10–12 秒，0.1.0 阶段原 15 秒限制曾使源码/安装包冒烟及一次全套测试超时。已将上限调整为 45 秒，保留取消；最终源码、重建安装包冒烟和 24 项测试通过。源码与安装包冒烟均包含真实系统加密往返成功。单文件组件启动成本仍需后续优化，不将失败的首轮记录隐藏。
- `native-smoke-real.log` 与 `packaged-smoke.log`：开发工程和实际 `.app` 都通过 renderer 加载、独立 robots 组件与真实 safeStorage 加密解密往返。另有 mock-keychain 探针不作为真实存储证明。退出时出现一次 Chromium 的 macOS task suppression 日志，成功结果和组件检查均已输出；不等同于持续运行稳定性验收。

## 当前限制

- 页面 HTML 的补充采集与 SiteOne 采集发生在不同请求；变动页面可能不同，报告保留请求渠道与时间，不构成原子快照。
- SiteOne 自带采集 robots 逻辑有前轮已识别的简化。最终规则判定使用独立 Protego，但不将采集成功/失败当作真实 AI bot 网络可达性。
- API 通用协议需兼容供应商所接受的参数。不能因服务声称“OpenAI-compatible”就保证所有模型端点可用。
- 一次只运行一个诊断；定时监测没有操作系统后台服务。
- 当前导出是 JSON/Markdown；未加入 PDF 与自动站点发布。
- 依赖 notices 已生成，非完整法律审计。
